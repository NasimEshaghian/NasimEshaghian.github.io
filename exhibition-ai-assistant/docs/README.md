# Exhibition AI Assistant

A Persian AI assistant that helps exhibition visitors find booth information, event details, and hall guidance.

## Files

- `exhibition_ai_assistant.html` — Project case-study page.
- `workflows/exhibition_ai_assistant_portfolio.json` — Main n8n workflow.
- `workflows/exhibition_demo_booking.json` — Demo booking workflow.
- `docs/exhibition_workflow_architecture.mmd` — Simple workflow diagram.
- `assets/chatbot_demo.mp4` — Chatbot demo video.

## Technologies

n8n, Ollama, Qwen, Nomic Embeddings, Supabase, Google Drive, and RAG.

## Note

The booking workflow is for demonstration only. It does not create real exhibition reservations.
