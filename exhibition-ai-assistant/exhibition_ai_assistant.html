About the Project

Exhibition information can be spread across many files. This assistant brings that information together, so visitors can ask questions in Persian instead of searching through files and schedules.

Find Companies

Visitors can search for companies and find their booth and hall details.

Check Events

Visitors can ask about talks, sessions, dates, and times.

Ask in Persian

The chatbot answers in Persian using the exhibition information provided to it.

Workflow

The workflow has two main parts: preparing exhibition information and answering visitor questions. The booking part is only a demo.

How It Works

Here is the process in five simple steps.

1

Read the Data

n8n reads the exhibition files from Google Drive. The files contain company, hall, and event information.

2

Prepare the Data

n8n cleans the information and adds labels so it can be found more easily.

3

Save for Search

Ollama creates text embeddings, and Supabase stores them for later search.

4

Receive a Question

The chatbot sends the visitor's message to n8n. A session ID helps keep the recent chat history together.

5

Give an Answer

Qwen uses the related exhibition information to create a Persian answer.

6

Test a Booking

A separate workflow can save a sample booking. It does not make a real reservation.

Tools I Used

These are the main tools used in the workflow.

n8n — connects the steps Ollama — runs the AI models Qwen — writes the answers Nomic — creates embeddings Supabase — stores searchable data Google Drive — stores source files

What I Built

I connected the exhibition files to a search system, so the assistant can find useful information.

Chat Flow

This is a portfolio demo. It does not make real exhibition bookings. The booking example only saves a sample record in a separate test table. The chat does not ask visitors to register with a phone number.
