Project Overview

The goal of this project was to develop a speech-to-text workflow for Persian audio using a fine-tuned Whisper-based automatic speech recognition model. The work covered more than model inference: it also involved preparing audio inputs, testing different recording formats, handling sample-rate requirements, and connecting the recognition pipeline to application interfaces.

Persian ASR

Fine-tuning and using a Whisper-based speech recognition model for Persian spoken input.

Audio Preparation

Preparing audio waveforms through resampling, noise reduction, normalization, and format conversion.

Application Integration

Connecting the model to test interfaces and API-based workflows for spoken audio input and text output.

Audio Processing Workflow

The supporting code includes audio preparation steps designed to make incoming recordings compatible with the model's expected input format.

Microphone / Audio File → Format Conversion → 16 kHz Waveform → Audio Enhancement → Whisper Features → Persian Transcription
01 · INPUT HANDLING

Recording & Format Conversion

Tested microphone capture and audio uploads, including OGG and WebM/Opus recordings. FFmpeg-based conversion prepared supported inputs as mono 16 kHz WAV/PCM audio for downstream processing.

02 · SIGNAL PREPROCESSING

Noise Reduction & Normalization

Used Librosa to load and resample waveforms to 16 kHz, Noisereduce for noise reduction, and Librosa normalization to adjust waveform amplitude before feature preparation.

03 · MODEL INPUT

Whisper Feature Extraction

Used the Whisper Processor and feature extractor to transform prepared audio waveforms into model-ready input features for Transformer-based speech recognition.

Audio augmentation experiments: An optional Audiomentations pipeline was prepared with Gaussian noise, pitch shifting, and time stretching to explore robustness. In the supplied preprocessing script, augmentation was disabled for the shown inference run; it is therefore described as an experimental pipeline rather than a confirmed step applied to every recording.

Model Fine-Tuning & Inference

I fine-tuned the Whisper-based model for the Persian speech recognition task and built inference code around the Hugging Face Transformers processor and PyTorch model. The inference experiments included local model loading, Persian-language transcription, and decoding strategies such as beam search.

Fine-Tuned Persian ASR

Adapted a Whisper-based model for Persian speech-to-text and used the resulting model in the demonstration. The exact checkpoint variant is not specified here because the project files include experiments with more than one Whisper configuration.

GPU-Aware Inference

Prototyped inference with PyTorch, including CUDA device selection, no-gradient execution, and mixed-precision settings in selected experiments.

Decoding Experiments

Tested generation settings, including beam-search decoding, while converting generated token sequences back into readable Persian text.

Application Prototypes

Built and tested different ways to expose transcription, including Flask and FastAPI endpoints, a Gradio microphone interface, and a WebSocket-based chunk-processing prototype.

Project Scope & Evaluation Note

The supplied code files document preprocessing, inference, and application integration, but do not include the complete fine-tuning script, dataset specification, training configuration, or a verified evaluation report. For that reason, this page does not state a Word Error Rate (WER), Character Error Rate (CER), accuracy score, training-data size, or benchmark comparison. The exact Whisper checkpoint variant is also left unspecified.
